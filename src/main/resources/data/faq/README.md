# FAQ 데이터 분류

분류의 단일 기준은 `category/faq_generation_categories.json`이다.
10개 메인카테고리와 43개 메인·서브카테고리 조합을 관리하며, 공용 초기 데이터는 `cleaned/faq_all_cleaned.jsonl` 1,000건이다.

- `com.vita.faq.taxonomy.FaqTaxonomy`가 JSON을 읽어 공통 검증을 제공한다.
- 배치는 메인·서브카테고리 모두 필수이며, 정확한 조합만 허용한다.
- 합성 데이터와 수집 데이터 모두 같은 검증을 적용한다. 출처에 따른 검증 예외는 없다.
- 관리자 API에서 선택적인 서브카테고리를 받는 경우 메인카테고리는 항상 검증하고, 서브카테고리가 제공되면 조합도 검증한다. PATCH는 기존 값과 병합한 최종 조합을 검증한다.
- 분류를 추가·변경할 때는 JSON 및 개수 메타데이터를 함께 수정하고, 기존 DB 데이터의 변환 필요성을 별도로 검토한다.
- 기존 15개 분류명은 자동 변환하지 않는다. 이전 자료는 새 분류로 정리한 뒤 적재해야 한다.
- 질문·답변과 하나 이상의 `source_policy_ids`는 배치 필수값이다.

전체 분류표와 실행 방법은 저장소의 `docs/faq-data.md`를 참고한다.
